# NFL Live Bet Tracker v2

Isolated from Pocket Chaise. Mobile-first live bet board with persistent ticket storage, duplicate protection, and a camera/photo intake UI.

## Current intake contract
The screenshot chooser is enabled, but automatic image parsing is deliberately not claimed yet. Tickets can be reviewed and saved through the form. The three Sept. 17 Lions–Bills tickets are seeded on first boot.

## Run
`npm start`

`DATA_FILE` can point at persistent storage. Default: `./data/bets.json`.
